# کارنامه

برنامهٔ سادهٔ ثبت کارهای روزانه. در طول روز کارها را می‌نویسید یا با صدا می‌گویید (تبدیل با **آوانگار**). به هر کار یک یا چند تگ می‌زنید، مثل «فراتر» یا «طراحی سایت شخصی». آخر روز برای هر تگ یک متن مرتب می‌گیرید و آن را در سامانهٔ تسک پیست می‌کنید.

## اجرا روی مک

روی فایل `start.command` دوبار کلیک کنید. بار اول محیط Python خودش نصب می‌شود. بعد مرورگر روی نشانی زیر باز می‌شود:

http://127.0.0.1:8770

برای تبدیل صدای ضبط‌شده به mp3، برنامهٔ `ffmpeg` لازم است (`brew install ffmpeg`). این برنامه همان است که پیام‌یار هم به آن نیاز دارد. اگر نصب نباشد، صدا بدون تبدیل برای آوانگار فرستاده می‌شود.

## توکن آوانگار

از ⚙ تنظیمات، توکن (gateway-token) را وارد کنید. اگر توکن قبلاً در پیام‌یار یا فراقرارداد ذخیره شده، می‌توانید آن را مستقیم منتقل کنید:

```sh
.venv/bin/pip install cryptography
.venv/bin/python scripts/import_avanegar_token.py ~/path/to/payamyar/data
```

اگر VPN روشن است و آوانگار وصل نمی‌شود، در تنظیمات «وای‌فای مک (en0)» را انتخاب کنید. همان روش پیام‌یار است: فقط درخواست‌های آوانگار از مسیر مستقیم می‌روند.

## کار با برنامه

- **ثبت کار:** متن را بنویسید یا 🎙 را بزنید (میان‌بر: `Alt+V`). برای پایان ضبط دوباره بزنید و برای لغو `Esc`. متن تشخیص‌داده‌شده داخل کادر می‌آید تا قبل از ثبت ویرایشش کنید. `Ctrl+Enter` کار را ثبت می‌کند.
- **تگ:** تگ‌های انتخاب‌شده در کادر ثبت، برای کارهای بعدی هم انتخاب می‌مانند. تگ را بعداً هم می‌شود زد: روی «+ تگ بزن» یا «± تگ» هر کار کلیک کنید. مدت کار (دقیقه) اختیاری است.
- **خروجی گزارش:** بازه (امروز، این هفته، این ماه یا دلخواه) و تگ را انتخاب کنید و «کپی متن» را بزنید. اگر یک تگ انتخاب شود، گزارش فقط کارهای همان تگ است. اگر «همهٔ تگ‌ها» انتخاب شود، هر تگ بخش جداگانه دارد.

نمونه خروجی:

```
گزارش کارهای انجام‌شده — فراتر
تاریخ: جمعه ۳ مهر ۱۴۰۵

۱. اصلاح صفحهٔ خدمات سایت فراترجمه و بررسی سئو (۱ ساعت و ۳۰ دقیقه)
۲. جلسه با تیم فروش
   پیگیری قرارداد
جمع: ۲ کار، مجموع زمان: ۱ ساعت و ۳۰ دقیقه
```

## داده و امنیت

همهٔ داده‌ها در `data/karnama.sqlite` روی همین دستگاه ذخیره می‌شوند. برای پشتیبان‌گیری از همین پوشه کپی بگیرید. برنامه ورود با رمز ندارد و فقط از خود دستگاه (127.0.0.1) پاسخ می‌دهد. توکن آوانگار داخل همین فایل ذخیره می‌شود و در صفحه نمایش داده نمی‌شود.

## آزمون

```sh
.venv/bin/python -m pytest -q
```

کد اتصال به آوانگار (`app/avanegar.py` و `app/service_network.py`) از پیام‌یار (سیستم یکپارچه‌سازی اطلاعات) برداشته شده است.
